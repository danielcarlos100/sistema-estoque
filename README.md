# Sistema de Estoque

Sistema de gerenciamento de estoque desenvolvido em **Python**, criado com o objetivo de praticar conceitos fundamentais de programação e estruturas de dados.

O sistema permite cadastrar, listar, buscar, alterar a quantidade e remover produtos do estoque através de um menu interativo no terminal.

---

##  Sobre o Projeto

Este projeto foi desenvolvido como parte dos meus estudos de programação em Python.

A ideia foi criar um sistema simples de estoque utilizando os conhecimentos adquiridos até o momento, principalmente:

- Funções
- Listas
- Dicionários
- Listas de dicionários
- Estruturas condicionais
- Estruturas de repetição
- Entrada e saída de dados
- Manipulação de dados

O projeto funciona diretamente pelo terminal e possui um menu para facilitar a utilização.

---

##  Funcionalidades

### 1. Cadastrar Produto

Permite cadastrar um novo produto informando:

- Nome
- Preço
- Quantidade

### 2. Listar Produtos

Exibe todos os produtos cadastrados no estoque.

### 3. Buscar Produto

Permite pesquisar um produto pelo nome utilizando um `for`.

### 4. Alterar Quantidade

Permite modificar a quantidade de um produto já cadastrado.

### 5. Remover Produto

Permite remover um produto do estoque.

### 6. Sair

Encerra o programa através do comando `break`.
